# Security Policy

## Reporting

Please do not disclose suspected vulnerabilities in a public issue. Use
GitHub's private vulnerability reporting feature when it is available for this
repository, or contact the repository owner privately through their GitHub
profile.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Do not include real credentials or personal data in a
report.

## Scope

Security-sensitive areas include firmware images, OTA partition switching,
third-party components, build and flashing instructions, and any change that
could expose local development data.
